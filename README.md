Hi everyone!

I’ve always liked the original EnderIO mod — especially its incredibly convenient Conduits. However, I often play modpacks that based on GregTech, where there's usually no room for the full EnderIO mod. At the same time, I frequently miss the utility that Conduits provide.

That’s why this fork was created: it strips everything from EnderIO except for the Conduits, offering a lightweight alternative focused solely on that functionality.

This mod only supports **Minecraft version 1.20.1**, and it's unlikely to receive future updates.

Huge thanks to the original EnderIO developers for their amazing work!
